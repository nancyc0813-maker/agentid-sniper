## 它会做什么

**发现新项目（六层）**
1. 每个新区块都扫：直接部署、CREATE2 部署器、工厂合约建立的新合约，合约码里有 Agent ID 登记合约（`0x60B9…022F`）就是 Agent ID 专属。
2. 代理合约（EIP-1967 / Beacon）会追到背后的实现合约再判断。
3. **热度保险**：同一个合约 3 分钟内被 12 个以上钱包呼叫（每笔 ≤0.2 BNB 的铸造都算），立刻检查（部署时漏看也能补上）。
4. **聪明钱包**：自动统计过去赚钱项目最早去打的 Agent ID 钱包，其中 2 个以上同时出手就提早检查。
5. **后端签名型项目**：合约里没写 Agent ID 检查（由网站后端签名验证）的新合约，只要打它的钱包六成以上持有 .ai 身份，也会被认定为 Agent ID 项目。
6. **铸造事件（最强保险）**：不管合约怎么部署（CREATE2、工厂、EIP-7702 智能账户…），只要同一个 NFT／代币 30 分钟内被铸给 6 个以上不同钱包，就检查是否 Agent ID 专属；常见函数不行时会照别人的调用内容重播（含别人地址的不重播）。

**自动铸造**
- 免费，或防女巫手续费 ≤ 0.001 BNB → 一发现就打（每个钱包）；每个钱包能打多份的会连续打，最多 10 份；每个钱包每天最多 1000 笔。
- 铸造在背景排队进行，不会拖慢扫描。
- 免费铸造拿到的代币自动加入持仓追踪，开池后到 5 倍、10 倍会通知，从最高回落 50% 自动全卖。
- 发现时还没开放 → 48 小时内每分钟重试，一开就打。
- **付费项目进场规则（依热度分三级）**：超热（累计 200 个以上 Agent ID 钱包参与，或 3 分钟内 30 个以上）进度 30% 就打；热（100 个以上，或 3 分钟内 15 个以上）进度 40%；一般项目进度 60%。读不到进度但热／超热的，照别人的方式跟打。快满或很热的项目每 15 秒检查一次，其他的在背景约每分钟轮流检查，多个钱包同时打，每个钱包每个项目 ≤ 20U（可在 config 调整）。
- **打不了的项目自动跳过**：需要官网签名、白名单或模拟一直失败的项目，标记后暂停重试（30 分钟后再试），记录在日志里；会先读项目方开放的份数（剩余额度／每个钱包上限／每笔上限）照着打，读不到再自动降到 5、3、2、1 份试；学别人打法时优先学最简单的那种。
- **看不懂的合约也能打**：读不到进度或不认得铸造函数时，自动学别人最近成功的铸造交易（包括要付 USDT 的，例如「USDT 铸造＋邀请人参数」这种），3 分钟内有 15 个以上钱包在打就跟进；需要 USDT 会自动用 BNB 换、授权后再打，份数放大到预算内最多 10 份。
- 支持四种付费铸造方式：BNB 报价型、USDT 份额型、单价×数量 NFT、直接转 BNB 就铸（价格取大家最常转的金额）。USDT 不够会自动用 BNB 换。
- 进度读法：先找“已售／上限”函数；没有的话看“铸造池剩多少币”（部署时持有量 vs 现在）。
- **只打新的**：两天前部署的老合约、已经开池交易的项目，不再自动铸造。
- 手动指定直接打的合约：config 加 `"forceMint": ["0x…"]`（不看进度与防钓鱼，只受 20U 上限与模拟检查；打到后只通知不自动卖）。
- 每笔都先模拟：不能有授权变化、不能扣到预期以外的资产、必须真的拿到东西，否则不送出。
- **不照抄转账／授权类指令**：学别人的铸造方式时，转账（transfer）、授权（approve）、NFT 转移这类指令一律不照抄，避免把刚铸到或原有的币转给别人。
- **照抄的交易里有别人的地址**（可能是收货人）：先换成自己的地址、再试零地址，都打不了就不打，避免付了钱东西却给别人。
- **免费铸造必须真的拿到东西**：预演显示净额为 0（例如拿到又被转走）就不送出。
- **授权后铸造失败会自动取消授权**，不留下多余的授权。

**防钓鱼／防连续发盘（硬性拦截）**
- **重复 DEV**：同一个部署者 24 小时内发 3 个以上**不同名**的 Agent ID 项目，他的免费／手续费项目不铸造。付费项目达到进场条件时：他之前有项目正常开盘、或只是同名重新部署 → 照打；没有纪录 → 钱没直接流走且至少 40 个钱包打过才打；撤过池／黑名单／钱直接流走 → 不打。
- **黑名单**：部署者之前的项目“打完 48 小时没开池”或“还没回本就崩”，之后他的项目一律不铸造。
- **同款合约批量部署**：同一份合约程序 24 小时内被部署 3 次以上，付费／手续费不打。
- **新钱包部署**：部署者约 8 小时内才开始使用的新钱包，付费不打。
- **假进度**：付费的进度必须由至少 20 个不同钱包打出来；钱直接流走（合约没留 BNB 也没开池）的要 40 个。
- **手续费型**只打 1 份，每个钱包每天手续费合计 ≤ 0.005 BNB；只有完全免费的才连续打。

**自动卖出（付费币，到价即执行）**

| 条件 | 动作 |
|---|---|
| 3 倍 | 卖出拿回本钱 |
| 5 倍 / 10 倍 | 各卖剩下的一半 |
| 开池 30 分钟内，从最高回落 35% | 全卖（速战模式） |
| 开池 20 分钟还没到 2 倍 | 全卖 |
| 之后从最高回落 60% | 全卖 |

免费币：5 倍、10 倍通知；开池 3 分钟后才开始记最高点（避开开盘瞬间拉高），之后从最高回落 50% 自动全部卖出。卖出一律换回 BNB。

高点和倍数一律用“每颗价格”计算（卖掉一部分后持仓变少，不会误判成暴跌）；价格取所有池子里最好的报价。卖出失败会间隔 1、2、4…最多 15 分钟重试，不会狂发通知；不到 0.3U 的零头不卖。

## 安装

**Windows 最简单的方式：下载 ZIP 解压后，双击 `一键安装.bat`**，照提示输入钱包和 TG，用币安 App 确认登录，就会自动在背景运行并开机自启。

以下是手动安装方式。需要：Windows（或 macOS / Linux）、Node.js 20+、币安 App 里已开通 Agentic Wallet 并领取 .ai Agent ID，且开启**开发者模式**。

```bash
npm install -g @binance/agentic-wallet
git clone <本仓库>
cd agentid-sniper
copy config.example.json config.json   # macOS/Linux 用 cp
```

编辑 `config.json`：
- `wallets`：你的 Agent ID 钱包地址。**一个钱包就能用**（用系统安装的 `baw`）。想同时用多个钱包再往下加；第二个以后要先跑 `setup_wallet2.bat`（独立的 baw 副本，避免互相踢下线），并在该钱包加上 `"bawDir": "baw2", "bawPkg": "baw2pkg", "instanceId": "wallet-2"`（选用）。
- `telegram`：Bot Token（找 @BotFather 创建）和你的 chat id。
- `paid` / `rules`：预算和卖出规则。
- `tokens`：想手动追踪的持仓（例如 `{ "sym": "XXX", "addr": "0x…", "cost": 10, "both": true }`；`hold: true` 只通知不卖；`sellNow: true` 立刻全卖）。

登录钱包（会给你一个链接，用对应币安账号的手机打开确认）：

```bash
node login.mjs 1
# 有第二个钱包再执行：node login.mjs 2
```

## 运行

```bash
start_hidden.vbs        # Windows 背景运行（自动重启）
# 或
node watch.mjs
```

- 修改 `watch.mjs` 存档后会自动重载。
- 停止：在同一资料夹建立一个 `WATCH_STOP` 文件。
- 日志在 `data/watch.log`，心跳在 `data/watch_heartbeat.txt`（含扫描落后区块数）。
- 内建看门狗：主循环卡住超过 8 分钟会自动重启。

## 注意

- 用公共节点，每分钟要下载约 130 个完整区块，**一天可能好几 GB 流量**，请用不限流量的网络。
- 币安 Agentic Wallet 每笔交易要先模拟再执行，约 10–15 秒，**拼不过专业 MEV 机器人的速度**；本工具的优势在 Agent ID 专属赛道（没有 .ai 身份的机器人打不了）。
- 开发者模式有到期时间，到期前 24 小时会提醒。
- 在手机上登录同一个 AI 钱包会把电脑这边踢下线，工具会发登录链接给你。
